# SEO Analysis Playbook

- Treat Search Console and crawl values as observations, not explanations.
- Consider query intent, ranking position, sample size, date range, and data completeness before suggesting work.
- A practical action should be specific, limited in scope, and measurable with a named metric.
- Never promise ranking or traffic gains.
- Cite only evidence IDs supplied with the finding. Do not calculate or invent source values.
- For uncertain or small samples, recommend gathering more data before changing the site.
- A technical crawler cannot reliably inspect content that appears only after client-side JavaScript.
