# Sparestracker Marketing Context

Sparestracker is a product whose growth work should focus on attracting people looking for relevant spare parts and helping them complete the intended conversion journey.

- Use only the supplied website, Search Console, and GA4 evidence. Do not assume product features or customer segments that the evidence does not describe.
- Treat the configured CTA and invitation submission events as separate steps. If an event is not configured, say conversion tracking needs setup; never report zero conversions.
- Use a mapped event's count only as an observed event count, not as unique users or completed sales.
- Prefer changes that can be reviewed manually and measured after release.
- Do not change the site, analytics settings, store listings, or marketing campaigns.
